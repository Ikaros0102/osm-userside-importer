# OSM Buildings to Userside Importer

Скрипт для автоматического получения полигонов зданий из OpenStreetMap (по заданным координатам) и подготовки данных для импорта в биллинг-систему **Userside**.

## Описание задачи

При работе с инфраструктурой сетей связи (или курьерскими службами) часто имеется список координат объектов, но нет точных контуров зданий и их адресов. Данный скрипт решает эту задачу:
1. Читает координаты (Широта, Долгота) из файла Excel.
2. Делает batch-запросы к **Overpass API** (OSM) для поиска зданий в радиусе 30 метров.
3. Сопоставляет исходные координаты с полигонами зданий с помощью геометрического анализа (`shapely`).
4. Формирует строку координат полигона в формате, который понимает Userside (`lat,lon,lat,lon`).
5. Извлекает этажность (`building:levels`), улицу и номер дома, после чего сохраняет всё в CSV файл.

## Особенности реализации
- **Обход лимитов API:** Запросы отправляются "чанками" (по 25 точек в запросе).
- **Graceful degradation:** Обработка HTTP-ошибок 429 (Too Many Requests) и 504 (Gateway Timeout) с автоматическим ожиданием и повторными попытками.
- **Оптимизация:** Дубликаты зданий автоматически фильтруются по `osm_id`.
